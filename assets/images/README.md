# Food Placeholder Images

This directory should contain fallback images for when food images fail to load.

## Required Files

1. **food-placeholder.png** - Generic food placeholder (recommended: 200x200px)
2. **fruit-placeholder.png** - Placeholder for fruits
3. **vegetable-placeholder.png** - Placeholder for vegetables
4. **protein-placeholder.png** - Placeholder for proteins (meat, fish, etc.)
5. **grain-placeholder.png** - Placeholder for grains and carbs
6. **dairy-placeholder.png** - Placeholder for dairy products

## Recommended Specifications

- **Format**: PNG with transparency or WebP
- **Size**: 200x200px (will be scaled as needed)
- **Style**: Simple, clean icon or silhouette
- **Colors**: Use neutral/warm colors (grays, soft oranges)
- **Background**: Transparent or very light gray (#f5f5f5)

## Quick Setup

You can use any of these free icon resources:
- [Flaticon](https://www.flaticon.com/search?word=food)
- [Icons8](https://icons8.com/icons/set/food)
- [Heroicons](https://heroicons.com/)

Or generate simple placeholders using tools like:
- [Placeholder.com](https://placeholder.com/)
- [PlaceIMG](https://placeimg.com/)
